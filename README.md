# warp-calculator

A simple web-based calculator for determining warp requirements for weaving projects.

## About

Warp Calculator helps weavers quickly calculate the total number of warp ends and total warp yardage needed for a project.

Enter:

* Width in reed (inches)
* Sett (ends per inch)
* Length of warp (yards)

The calculator returns:

* Total warp ends
* Total warp yards

## Why I Made It

Warp calculations are simple but repetitive. This project turns the basic calculations I use for weaving into a quick, accessible tool that can be used from a phone or computer.

## How to Use

1. Enter the width of your project in the reed.
2. Enter your sett in ends per inch.
3. Enter the length of your warp in yards.
4. Select **Calculate** to see your warp requirements.
5. Select **Clear** to reset the calculator.

## How It Works

**Total warp ends**

`Width in reed × Sett`

**Total warp yards**

`Total warp ends × Length of warp`

HTML, CSS, and JavaScript.
